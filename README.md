# Викторина 🎯

Веб-викторина для детей: выбираешь тему, отвечаешь на вопросы с картинками,
набираешь очки. Учебно-развлекательный проект для детей со сложностями
развития — с акцентом на простой интерфейс, крупные кнопки и наглядные
изображения.

🔗 **Live-демо:** [fixius.pythonanywhere.com](https://fixius.pythonanywhere.com/)

## Возможности

- 📚 Несколько тем (например, «Метро», «Строительная техника»), каждая — отдельный JSON-файл.
- 🖼 Каждый вопрос может содержать картинку (подгружается с Wikimedia).
- 🎲 Варианты ответа перемешиваются при каждом запуске.
- 💾 Прогресс сохраняется в сессии — можно закрыть вкладку и продолжить позже.
- 🔄 Кнопки «Заново» и «Сменить тему» — сброс прогресса в один клик.
- 📱 Простой адаптивный интерфейс на чистом HTML/CSS/JS.

## Технологии

| Слой     | Что используется              |
|----------|-------------------------------|
| Backend  | Python 3.13, Flask 3.1        |
| Frontend | Vanilla JS, Jinja2, CSS       |
| Хранение | `session` Flask (in-memory)   |
| Данные   | JSON-файлы в `quizzes/`       |
| Хостинг  | PythonAnywhere                |
