# Викторина 🎯

Веб-викторина для детей: выбираешь тему, отвечаешь на вопросы с картинками,
набираешь очки. Учебно-развлекательный проект для детей со сложностями
развития — с акцентом на простой интерфейс, крупные кнопки и наглядные
изображения.

## Возможности

- 📚 Несколько тем (например, «Метро», «Строительная техника»), каждая — отдельный JSON-файл.
- 🖼 Каждый вопрос может содержать картинку (подгружается с Wikimedia).
- 🎲 Варианты ответа перемешиваются при каждом запуске.
- 💾 Прогресс сохраняется в сессии — можно закрыть вкладку и продолжить позже.
- 🔄 Кнопки «Заново» и «Сменить тему» — сброс прогресса в один клик.
- 📱 Простой адаптивный интерфейс на чистом HTML/CSS/JS.

## Запуск локально

### 1. Клонировать репозиторий

```bash
git clone https://github.com/kazarin-1983/MyVibeCoding.git
cd MyVibeCoding
```

### 2. Создать виртуальное окружение

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows (PowerShell):**
```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Запустить сервер

```bash
python app.py
```

Приложение будет доступно по адресу **http://127.0.0.1:5000/**.

> По умолчанию Flask запускается в режиме `debug=True` — код перезагружается
> при изменениях. Для продакшена этот флаг нужно убрать.

### 5. (Опционально) Деплой на PythonAnywhere

1. Загрузи проект в свою директорию на PythonAnywhere.
2. В разделе **Web** создай новое Flask-приложение.
3. Укажи путь к `app.py` и активируй виртуальное окружение с зависимостями.
4. Нажми **Reload**.

## Как добавить новую викторину

1. Создай файл `quizzes/<id>.json`, где `<id>` — короткое латинское имя
   (например, `space.json`). Оно станет идентификатором темы в API.
2. Заполни файл массивом вопросов:

```json
[
  {
    "question": "Что это за строительная техника?",
    "options": [
      "Экскаватор",
      "Бульдозер",
      "Погрузчик",
      "Автокран"
    ],
    "answer": "Экскаватор",
    "photo_url": "https://commons.wikimedia.org/wiki/Special:FilePath/Caterpillar%20330%20excavator%20on%20a%20pile%20of%20dirt.jpg"
  }
]
```

**Поля:**

| Поле        | Обязательное | Описание                                       |
|-------------|--------------|------------------------------------------------|
| `question`  | да           | Текст вопроса                                  |
| `options`   | да           | Массив вариантов ответа (строки)               |
| `answer`    | да           | Правильный ответ — должен быть из `options`    |
| `photo_url` | нет          | Ссылка на изображение                          |

3. Перезапусти сервер — викторина появится в списке автоматически.

> ℹ️ Человекочитаемое название темы задаётся в словаре `names` внутри
> `app.py` в функции `get_quizzes()`. Если не добавить туда запись,
> в интерфейсе отобразится `id` файла.

## API

Все эндпоинты возвращают JSON. Прогресс хранится в серверной сессии
(куки), отдельно для каждой викторины.

| Метод | Путь                       | Описание                                      |
|-------|----------------------------|-----------------------------------------------|
| GET   | `/`                        | Главная страница                              |
| GET   | `/api/quizzes`             | Список доступных викторин                     |
| GET   | `/api/questions/<quiz_id>` | Все вопросы викторины                         |
| GET   | `/api/progress/<quiz_id>`  | Текущий прогресс пользователя                 |
| POST  | `/api/progress/<quiz_id>`  | Обновить прогресс (`round`, `score`, …)       |
| POST  | `/api/reset/<quiz_id>`     | Сбросить прогресс по викторине                |

**Пример ответа `GET /api/progress/metro`:**

```json
{
  "round": 1,
  "score": 0,
  "answered_ids": [],
  "finished": false
}
```

## Тестирование

Проект покрыт тестами на **pytest** с использованием встроенного
Flask test client — без запуска реального сервера и без браузера.

### Установка

```bash
pip install pytest
```

### Запуск

Из корня проекта:

```bash
pytest tests/ -v
```

### Что покрыто

- ✅ Список викторин (`GET /api/quizzes`)
- ✅ Получение вопросов (`GET /api/questions/<id>`) и 404 для несуществующей темы
- ✅ Прогресс по умолчанию (`GET /api/progress/<id>`)
- ✅ Сохранение прогресса (`POST /api/progress/<id>`)
- ✅ Сброс прогресса (`POST /api/reset/<id>`)
- ✅ Изоляция прогресса между разными викторинами

Подробности и полный список тестов — в `tests/test_app.py`.
